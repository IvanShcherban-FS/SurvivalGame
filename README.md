Survival Game (Console) 
Консольна гра виживання на Python з режимами, рандомними подіями, системою очок та збереженням результатів у файл.
Є вибір мови English / Українська.
     
     ===== Функції проєкту===== 
  1.Консольне меню
  2.Вибір мови: EN / UA
  3. 5 режимів гри
  4.Випадкові події (ворог, пастка, скарби)
  5.HP bar (візуальна шкала здоров’я)
  6.Відпочинок (лікування) з обмеженнями (HP max та Hardcore)
  7.Збереження результатів у файл scores.txt
  8.Захист від неправильного вводу (меню, режими, дії)
  
     -----Дії гравця-----
  1. Дослідити територію
  2. Відпочити
  3. Ризикнути заради скарбу

         -----Події-----
   1.Режими гри (1–5) 🕹
   2.Classic — стандартний режим, потрібно вижити max_turn ходів
   3.Endless — гра триває, поки HP > 0 (без ліміту ходів)
   4.Greedy — потрібно набрати goal_coins монет за greedy_turns ходів
   5.Hardcore — Rest можна використати лише 1 раз за гру
   6.Chaos — кожен хід випадковий ефект:
          Double Damage (урон ×2)
          Double Coins (монети ×2)
          Bonus Heal (+10 HP)
          Nothing

        -----Запуск-----
Запустити main.py 
Додаткові бібліотеки не потрібні (тільки random, він стандартний)

     -----Управління-----
   У грі всюди вводяться цифри:
Головне меню:
   1 — Start Game
   2 — Results
   3 — Exit

Дії під час гри:
   1 — Explore (дослідження)
   2 — Rest (відпочинок/лікування)
   3 — Risk (ризик)

     -----Налаштування-----
Налаштування (можна змінювати в коді)
На початку main.py можна змінити баланс гри:
start_hp — максимальне HP
max_turn — кількість ходів у Classic
enemy_dm — урон ворога
trap_dm — урон пастки
heal_amount — скільки лікує Rest
coin — базові монети за скарб
goal_coins — ціль монет у Greedy
greedy_turns — ліміт ходів у Greedy
bar_len — довжина HP bar
