Survival Challenge — Консольна гра на виживання

        -----Опис Гри-----

  1. Гравець починає з 100 HP
  2. Потрібно вижити 10 ходів
  3. Кожен хід гравець обирає дію
  4. Подія залежить від вибору гравця та випадковості 
  5. Якщо HP = 0 -> програш
  6. Якщо 10 ходів пройдено -> перемога
  
        
        -----Дії гравця-----
  1. Дослідити територію
  2. Відпочити
  3. Ризикнути заради скарбу

         -----Події-----
  1. напад ворога (-30 HP)
  2. аптечка (+20 HP)
  3. скарб (+10 монет)
  4. пастка (-15 HP)
  5. нічого не сталось
  

        -----Запуск-----
Запустити main.py
